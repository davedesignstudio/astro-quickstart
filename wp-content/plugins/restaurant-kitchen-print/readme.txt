Automatically print kitchen tickets when WooCommerce restaurant orders are placed.

== Description ==

Queues kitchen tickets on new orders and prints them via a Kitchen Station browser page or PrintNode.

Features:

* Pickup / delivery / dine-in checkout fields
* Kitchen notes and station routing on products
* Auto-print queue + REST API for kitchen devices
* Thermal ticket templates (58mm / 80mm)
* Optional PrintNode integration

== Installation ==

1. Install and activate WooCommerce
2. Upload and activate this plugin
3. Open WooCommerce → Settings → Kitchen Print
4. Open /kitchen-station/ on a kitchen device and connect with the station token
