Restaurant online ordering helpers for WooCommerce with automatic kitchen ticket printing.

== Description ==

When a customer places an order, this plugin immediately builds a kitchen ticket and can:

* Send it to a receipt printer through PrintNode
* Show it on a live kitchen display with optional browser printing

Also adds pickup/delivery/dine-in fields, requested time, and kitchen notes at checkout.

== Installation ==

1. Upload the `restaurant-order-tickets` folder to `/wp-content/plugins/`
2. Activate the plugin
3. Ensure WooCommerce is active
4. Configure WooCommerce → Kitchen Tickets

== Frequently Asked Questions ==

= Do I need PrintNode? =

PrintNode is recommended for silent automatic printing. Without it, use the kitchen display auto-print fallback.
